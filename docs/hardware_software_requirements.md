# Hardware & Software Requirements

- **CPU:** Any modern x86_64 or arm64 CPU (single-node, no GPU required).
- **Memory:** ≥ 2 GB RAM (peak usage < 1.5 GB).
- **Disk:** ≥ 250 MB free disk space.
- **Software:** Python 3.10–3.13 (CI and Colab verified on Python 3.13), open-source packages pinned in `requirements-lock.txt` (`numpy`, `scipy`, `matplotlib`, `cvxpy`, `clarabel`, `pytest`). No commercial solvers required.
