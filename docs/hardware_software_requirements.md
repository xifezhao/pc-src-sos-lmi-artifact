# Hardware and Software Requirements

- **OS**: Linux, macOS, or Windows (x86_64 or ARM64); tested on Google Colab Ubuntu x86_64.
- **Python**: >= 3.10.
- **Packages**: `numpy`, `scipy`, `cvxpy`, `clarabel`, `scs`, `pyyaml`, `matplotlib`, `pytest`.
- **RAM / Disk**: >= 2 GB RAM, >= 200 MB free disk space. No GPU or commercial solver license required.
